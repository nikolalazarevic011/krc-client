# Kingdom Running Club (KRC) Dashboard

A web dashboard application for Kingdom Running Club members to view their classes, access reference handouts, perform homework assignments, watch exercise videos, and obtain their wellness certificates.

## Language

**Class**:
A structured unit of instruction representing a single lesson or week in the curriculum.
_Avoid_: Course, session

**Exercise**:
A physical workout or instruction activity associated with a Class, which includes videos and reference PDFs.
_Avoid_: Workout, task

**Homework**:
An independent assignment or practice task assigned directly to members.
_Avoid_: Assignment, task

**Handout**:
A reference document or instructional PDF file attached to a Class.
_Avoid_: Document, sheet, file

**Certificate**:
The Health and Wellness Certificate awarded to members, accessed via QR code or external Jotform.
_Avoid_: Award, credential

**Member**:
A registered and authenticated student/runner using the dashboard.
_Avoid_: User, account, student
